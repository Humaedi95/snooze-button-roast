A tiny Python program that writes a one-line roast of an alarm clock
that rings at 6 AM on a Saturday to `/output/entry.txt`.

## Usage

```sh
python3 main.py
```

The entry (120 characters, one line):

> You ring at 6 AM on a Saturday like the weekend owes you rent — even the sun sleeps in, and it actually has a job.
